# USC (ISSAI Uzbek Speech Corpus): проверка текстов

Отдельный проект для второго источника по ТЗ: статистика по текстам и длительностям USC. Тексты и аудио (`.txt` и `.wav`) лежат в папках `train`, `dev`, `test`. Данные в git не попадают.

## Запуск
```bash
go run . dev
go run . test
go run . train > report-train.txt   # около 100 тысяч пар, несколько минут
```
Программа читает пары `NAME.txt` + `NAME.wav` в папке сплита, длительность берёт из заголовка WAV и считает: пары, часы, кириллицу, эмодзи и значки, символы вне `a-z`, апострофа и пробела.

## Данные

| Часть | Пар | Часов | Букв |
| --- | --- | --- | --- |
| train | 100 767 | 96,40 | 3 542 873 |
| dev | 3 783 | 4,00 | 147 463 |
| test | 3 837 | 4,50 | 175 897 |
| всего | 108 387 | 104,90 | 3 866 233 |

В ТЗ для USC указано 105 ч.

Формат аудио (проверено `ffprobe` на одном файле из dev): `pcm_s16le`, 16 кГц, моно, 16 бит.

## Результат проверки текстов
- Кириллица: 0 текстов во всех частях.
- Эмодзи и значки: 0.
- Пустые тексты: 0. Пары без `.wav` или `.txt`, нечитаемые `.wav`: 0.
- Символы вне `a-z` и пробела: только обычный апостроф `'` (U+0027): 98 782 раза в train, 3 392 в dev, 4 193 в test. Других видов апострофа нет.
- Тексты строчные, без знаков препинания, одной строкой.

## Хронология
1. Скачан USC (`ISSAI_USC`: `train`, `dev`, `test`, пары `.txt` и `.wav`).
2. Осмотрена структура и формат файлов.
3. Написана программа `main.go`, прогнаны `dev`, `test`, `train`.

## Открытые вопросы
- Пустые тексты после нормализатора (например, из одних пауз «eee») не проверялись.
- Написание «j» вместо «y» не проверялось, это задача для фильтра по CER (этап 3 ТЗ).
